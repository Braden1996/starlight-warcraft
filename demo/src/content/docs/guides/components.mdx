Import every component from `starlight-warcraft/react`. Each one passes the usual HTML attributes through to its
element, and appends your `className` after its own.

## Button

<div class="demo-row">
  <Button>Accept quest</Button>
  <Button variant="frame">Frame</Button>
  <Button size="sm">Small</Button>
  <Button variant="frame" size="sm">
    Small frame
  </Button>
  <Button disabled>Disabled</Button>
</div>

```tsx
<Button>Accept quest</Button>
<Button variant="frame" size="sm">Small frame</Button>
<Button asChild>
  <a href="/start/">A link styled as a button</a>
</Button>
```

| Prop      | Values                 | Default     |
| --------- | ---------------------- | ----------- |
| `variant` | `"default"`, `"frame"` | `"default"` |
| `size`    | `"default"`, `"sm"`    | `"default"` |
| `asChild` | `boolean`              | `false`     |

`asChild` styles the only child (a link, say) instead of rendering a `button`.

```tsx
<Card>
  <CardHeader>
    <CardTitle>The Old Road</CardTitle>
    <CardDescription>Recommended level 12</CardDescription>
  </CardHeader>
  <CardContent>Follow the road east to the watchtower.</CardContent>

```

`Card` takes `size`: `"default"` or `"sm"`. `CardHeader`, `CardTitle`, `CardDescription`, `CardContent` and
`CardFooter` are plain `div`s with the matching class.

## Panel

A tooltip-style panel with an item-quality border.

<div class="demo-grid">
  <Panel>Common</Panel>
  <Panel quality="uncommon">Uncommon</Panel>
  <Panel quality="rare">Rare</Panel>
  <Panel quality="epic">Epic</Panel>
  <Panel quality="legendary">Legendary</Panel>
</div>

```tsx
<Panel quality="epic">Epic</Panel>
```

`quality` is `"common"` (the default), `"uncommon"`, `"rare"`, `"epic"` or `"legendary"`. `panelClassName(quality)`
returns the same classes for elements you render yourself, such as a hover card.

## HoverCard

The card that `HoverCards` shows when you hover a name in a checked Luau code block, or a link you give it a source
for. Its `quality` picks the border, and `error` turns the title red.

<div class="demo-grid">
  <HoverCard card={{ title: "Inferred type", kind: "Luau, new solver", body: "local frame: Frame" }} />
  <HoverCard
    card={{ title: "CreateFrame", kind: "Function · typed", body: "CreateFrame(frameType: string): Frame", quality: "rare" }}
  />
  <HoverCard
    card={{ title: "TypeError", kind: "the line marked -- error", body: "Unknown global 'GetQuestLogTitle'", error: true }}
  />
</div>

```tsx
<HoverCard card={{ title: "CreateFrame", kind: "Function · typed", body: "CreateFrame(frameType: string): Frame", quality: "rare" }} />
```

Mount `<HoverCards client:idle />` once per page to show these on hover. Pass `sources` for your own anchors.

## Spinner

<div class="demo-row">
  <Spinner />
  <Spinner style={{ width: "4rem", height: "4rem" }} aria-label="Summoning" />
</div>

```tsx
<Spinner aria-label="Searching" />
```

The spinner has `role="status"` and the label "Loading" unless you pass `aria-label`. It stops animating when the
reader prefers reduced motion.
